# data/

One node per data source family for Pittsburgh and Allegheny County, each with endpoints, resource IDs, field names, counts, query gotchas, freshness, and a verification tag on every source (all probed 2026-09-26). The parcel spine is [parcels and assessments](parcels-and-assessments.md); inside the city, [zoning GIS](zoning-gis.md) and [zoning code text](zoning-code-text.md) supply the binding rules, and [municipal zoning outside the city](municipal-zoning-outside-city.md) covers the suburban gap. Site constraints are in [environmental constraints](environmental-constraints.md) and [LiDAR slope](lidar-slope.md); capacity data we did not find publicly (⚠ search only *(corrected 2026-09-26 per docs/04-critique.md row 20)*) and the proxies we have are in [infrastructure](infrastructure.md). Ground truth and approval durations come from [permits and outcomes](permits-and-outcomes.md) and [ZBA decisions](zba-decisions.md). Ownership, availability and distress are in [land availability and title](land-availability-and-title.md); sales, rents, AMI and incentive geographies in [market and affordability](market-and-affordability.md). [Organizer data catalog](organizer-data-catalog.md) summarizes the organizers' catalog (⚠ 60 rows, 58 distinct sources *(corrected 2026-09-26 per docs/04-critique.md row 19)*) and maps it to these nodes. Recurring traps: WPRDC `datastore_search_sql` with `WHERE` returns 403; slope polygons have holes (intersect the parcel polygon); PA DEP needs JSON geometry; OneStopPGH new-construction permits were recoded in 2025 and queries are slow; many city layers were last edited in 2023. Source sweeps are in [../../sweeps/](../../sweeps/); tag rules and the corrections log are in [../README.md](../README.md).
